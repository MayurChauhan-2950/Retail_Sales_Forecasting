Status: these files were generated by a script from `../power_query`, `../dax/measures.dax`,

## Steps

1. Install/update Power BI Desktop (a recent release; TMDL and PBIR need a 2024+ version).
2. File > Options and settings > Options > Preview features. Tick:
   - "Power BI Project (.pbip) save option"
   - "Store semantic model using TMDL format"
   - "Store reports using enhanced metadata format (PBIR)" (if shown)
   The exact wording differs between versions. Click OK and restart Power BI Desktop.
3. File > Open report > Browse this device > select `powerbi\pbip\retail_sales_forecast.pbip`.
4. Check the DataFolder path: the model expects the CSVs in
   `C:\Users\devch\Downloads\DSC\Projects\IP_Retail_Sales_Analytics\data` (subfolders `curated` and `forecast`).
   If the project is elsewhere: Home > Transform data > Edit parameters > DataFolder.
   If `data\curated` / `data\forecast` is missing run `python scripts/run_all.py` first.
5. Home > Refresh. If a privacy-level or file-access prompt appears, allow it for local files.
6. Calculated tables `RFM` and `Top N` are filled on refresh as well.

## If Power BI Desktop shows an error

- TMDL parse error: send me the complete message (it names a file and a line number, for example
  `tables\fact_sales.tmdl line 12`). Do not edit files blindly; I will fix the generator and regenerate.
- Report-only error (mentions `report.json`, `pages.json`, `version.json` or the theme): the model is probably
  fine. Delete the whole `themeCollection` and `resourcePackages` entries in
  `retail_sales_forecast.Report\definition\report.json`, try again, then apply the theme through
  View > Themes > Browse for themes > `theme\retail_forecast_theme.json`. If it still fails, send me the message.
- Refresh error "could not find file": the DataFolder path is wrong (step 4).
- Refresh error in a calculated table (`RFM`): send me the message; the DAX was never executed anywhere.

When the project opens and the checks pass, use File > Save as to keep working in PBIP, or save a `.pbix`
copy if you need `retail_sales_forecast.pbix`.
